# Как contribute в Remotix

Спасибо, что интересуетесь проектом! Remotix — открытый проект, и любой вклад
(код, документация, отчёт об ошибке) приветствуется.

## Быстрый старт

```bash
git clone https://github.com/flytimopheev-sketch/remotix.git
cd remotix
cargo build --release
```

Зависимости crates.io уже лежат в каталоге `vendor/`, поэтому сборка идёт
полностью офлайн.

## Перед отправкой Pull Request

```bash
cargo fmt                 # форматирование
cargo clippy --all-targets # статический анализ
cargo test                # тесты
cargo build --release     # сборка release-версии
```

Пожалуйста, убедитесь, что все три команды проходят без ошибок и предупреждений.

## Стиль кода

- Rust 2021 edition, имена в `snake_case`, типы в `CamelCase`.
- Комментарии и документация — на русском языке (проект русскоязычный).
- Публичные функции снабжены doc-комментарием `///` с описанием поведения.
- Не добавляйте новые зависимости без обсуждения в Issue: каждый crate
  увеличивает размер RPM-пакета и усложняет офлайн-сборку.

## Структура проекта

| Каталог | Назначение |
| --- | --- |
| `src/` | код приложения |
| `src/ui/` | GTK4-интерфейс |
| `src/protocols/` | реализации протоколов (SSH, RDP, VNC) |
| `src/db/` | SQLite, шифрование, репозиторий |
| `resources/` | значки и шаблоны интерфейса |
| `packaging/` | RPM-спецификация, ярлык, метаданные AppStream |
| `packaging/ci/` | скрипты окружения EL9 для CI |

## Сборка RPM

```bash
./make-rpm-sources.sh
```

Скрипт подготовит `vendor/`, соберёт исходники и запустит `rpmbuild`.
Пакет появится в `~/rpmbuild/RPMS/`.

CI делает то же самое, но внутри `chroot` с AlmaLinux 9 — это окружение
ближе всего к РЕД ОС 8.

## Как сообщить об ошибке

Откройте [Issue](https://github.com/flytimopheev-sketch/remotix/issues) и
обязательно укажите:

1. Версию РЕД ОС (`cat /etc/os-release`) и версию Remotix (`remotix --version`).
2. Что ожидалось и что получилось.
3. Логи запуска из терминала — в GTK-приложении сообщения об ошибках видны
   только в консоли:

   ```bash
   remotix 2>&1 | tee /tmp/remotix.log
   ```
