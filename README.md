# Remotix — клиент удалённого доступа (RDP/VNC/SSH)

Единый интерфейс для подключения к удалённым рабочим столам и серверам
для **РЕД ОС 7/8**, аналог Remmina и RustDesk. Работает полностью офлайн,
без облака и телеметрии.

## Возможности

- **Профили подключений**: RDP, VNC, SSH; закладки и группы; поиск,
  фильтрация, сортировка; импорт/экспорт (JSON, зашифрованный).
- **Безопасность**: мастер-пароль (Argon2id) → AES-256-GCM шифрование
  учётных данных в SQLite; NLA для RDP по умолчанию; SSH-туннель для VNC;
  блокировка интерфейса после N минут бездействия.
- **Подключения**: отдельная вкладка/окно на сессию; RDP — рабочий стол,
  горячие клавиши, полноэкранный режим; SSH — встроенный терминал (VTE),
  вкладки, копирование/вставка, масштаб шрифта, цветовые схемы.
- **SFTP**: двухпанельный клиент — загрузка/скачивание, создание папок,
  переименование, удаление, история путей.
- **История подключений**: длительность, статус, код ошибки, фильтры,
  экспорт в CSV.

## Стек

Rust (stable) · GTK4 (gtk4-rs) · rusqlite (SQLite, bundled) · argon2 ·
aes-gcm · ssh2 (libssh2) · FreeRDP (FFI/ironrdp) для RDP · rfb/libvncclient
для VNC · RPM-упаковка для РЕД ОС.

## Сборка

```bash
cargo build --release
```

Требуются dev-пакеты: `gtk4-devel`, `libssh2-devel`, `freerdp-devel`,
`openssl-devel`.

## Схема БД

`meta` (соль Argon2, параметры, верификатор), `groups`, `profiles`
(учётные данные — BLOB, зашифровано AES-256-GCM), `connection_history`;
индексы по имени, хосту, группе и дате — см. `src/db/schema.rs`.

## Установка (RPM, РЕД ОС)

```bash
rpmbuild -bb packaging/remotix.spec
dnf install ~/rpmbuild/RPMS/*/remotix-1.0.0-*.rpm
```

Файлы устанавливаются в:
`/usr/bin/remotix`, `/usr/share/applications/remotix.desktop`,
`/usr/share/icons/hicolor/scalable/apps/remotix.svg`,
`/usr/share/metainfo/remotix.metainfo.xml`.

## Двухступенчатый вход по SSH (admin → su → root)

На серверах, где прямой root-логин запрещён (`PermitRootLogin no`),
профиль SSH работает в две ступени:

1. Аутентификация под **локальным администратором** (пароль или ключ).
2. Remotix автоматически открывает PTY-канал, выполняет `su -` и
   подставляет **пароль root** (хранится зашифрованным) в ответ на
   prompt `Password:`. Терминал продолжает работу уже под root.

Включается галкой «переключаться в root (su -)» в редакторе профиля;
пароль root — отдельное зашифрованное поле `root_password` в БД.

## Буфер обмена по RDP (туда и обратно)

Канал `cliprdr` включён по умолчанию:

- **локальный → удалённый**: копирование в Remotix, вставка на сервере;
- **удалённый → локальный**: копирование на сервере (Ctrl+C), вставка
  в локальных приложениях (Ctrl+V) через GTK-клипборд.

Управляется флагами `clipboard`, `clipboard_to_remote`,
`clipboard_from_remote` в `rdp_options` профиля.


## Быстрый старт ✨

**1. Первый запуск.** Remotix попросит придумать **мастер-пароль** — это ключ
ко всем вашим сохранённым паролям. Он нигде не хранится, восстановить его
невозможно, поэтому запомните его или запишите в надёжном месте (менеджер
паролей, бумажка в сейфе).

**2. Добавьте первое подключение.** Нажмите **«Новый профиль»** (или `Ctrl+N`):
- выберите протокол — **SSH**, **RDP** или **VNC**;
- укажите хост, порт и логин;
- введите пароль (или путь к SSH-ключу) — он будет зашифрован
  Argon2id + AES-256-GCM и сохранён в локальную базу.

**3. Быстрое подключение.** Не хочется создавать профиль? Впишите
`user@host` в строку быстрого подключения и нажмите Enter — откроется
SSH-сессия во встроенном терминале.

**4. Работайте.** Каждая сессия открывается отдельной вкладкой. Для SSH
доступны копирование/вставка, масштаб шрифта и цветовые схемы; для SFTP —
двухпанельная передача файлов. История всех подключений ведётся
автоматически и выгружается в CSV.

**5. Блокировка.** Отходите от компьютера? `Ctrl+L` мгновенно заблокирует
интерфейс — без повторного ввода мастер-пароля данные не увидеть.

> 💡 Совет: для серверов, где root-вход по SSH запрещён, включите в профиле
> галку «переключаться в root (su -)» и сохраните пароль root — Remotix сам
> выполнит двухступенчатый вход.

## Ограничения / принципы

- Никакого облака и внешней синхронизации.
- Никакой телеметрии.
- Все зависимости — из офлайн-репозитория РЕД ОС или из исходников.
- Поддержка тёмной темы GTK, ssh-agent, индикатор статуса подключения.

## Критерии готовности (см. ТЗ)

1. Сборка без ошибок: `cargo build --release`.
2. Создание мастер-пароля и профилей RDP/VNC/SSH.
3. SSH-подключение со встроенным терминалом.
4. SFTP-клиент: загрузка/скачивание файлов.
5. RDP/VNC подключаются к тестовым серверам.
6. Учётные данные зашифрованы и не читаются в базе напрямую.
7. История подключений ведётся и фильтруется.
8. Импорт/экспорт профилей работает.
9. RPM-пакет устанавливается, приложение доступно из меню.
