# История изменений

Все значимые изменения проекта фиксируются в этом файле.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект следует [Semantic Versioning](https://semver.org/lang/ru/).

## [1.1.0] — 2026-10-21

### Исправлено

- **Приложение не запускалось в РЕД ОС.** При старте рабочее окружение может
  передать приложению URI или файл; GApplication без флага
  `G_APPLICATION_HANDLES_OPEN` в этом случае завершался с сообщением
  `GLib-GIO-CRITICAL: This application can not open files.` и не показывал
  графический интерфейс. Добавлены флаг и обработчик сигнала `open`
  ([`src/main.rs`](src/main.rs), [`src/app.rs`](src/app.rs)).
- **Мастер-пароль больше не «съедал» окно.** Диалог разблокировки не был
  привязан к приложению и не умел отдавать ключ: главное окно не создавалось,
  процесс завершался сразу после запуска. Теперь диалог — полноценное окно
  приложения с обработчиком ввода ([`src/ui/master_password.rs`](src/ui/master_password.rs)).
- **Кнопка «Быстрое подключение»** брала значение из строки поиска, а не из
  своего поля ввода ([`src/ui/main_window.rs`](src/ui/main_window.rs)).
- **Ошибка открытия базы данных** приводила к панике без объяснений — теперь
  показывается понятное окно с текстом ошибки.
- Каталог `~/.local/share/remotix` создаётся автоматически, путь берётся из
  `$XDG_DATA_HOME` ([`src/config.rs`](src/config.rs)).

### Добавлено

- Список профилей подключений с поиском и фильтрацией по названию, адресу и
  логину.
- Редактор профиля: протокол, адрес, порт, логин, пароль, сохранение и
  правка существующих профилей.
- Блокировка интерфейса по `Ctrl+L` с повторным запросом мастер-пароля.
- Горячие клавиши: `Ctrl+F` (поиск), `Ctrl+I` (о программе), `Ctrl+Q` (выход).
- Диалог «О программе» с ссылками на репозиторий и текстом лицензии.
- Метод `Database::update_profile` для правки профилей.

### Упаковка и оформление

- **Восстановлена офлайн-сборка.** В каталоге `vendor/` у трёх файлов пакета
  `vcpkg` не совпадали контрольные суммы, из-за чего `cargo build --offline`
  падал с ошибкой «the listed checksum of … has changed». Файлы восстановлены
  из оригинального пакета crates.io — теперь офлайн-сборка из репозитория
  работает без сети.
- RPM: зависимость `libssh2` объявлена явно, добавлена установка текста
  лицензии, убран отдельный debuginfo-пакет, метаданные приведены к
  единому виду.
- `.desktop`-файл приведён к спецификации Freedesktop, добавлены `Keywords`,
  `TryExec` и `StartupWMClass`.
- AppStream-метаданные дополнены описанием, ссылками на баг-трекер и
  списком изменений релизов.
- Полностью переработан README, добавлены `CHANGELOG.md` и `CONTRIBUTING.md`,
  шаблоны Issue и Pull Request.
